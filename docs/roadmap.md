# Development Roadmap

This file shall act as a living document of the roadmap for [Undertone](../README.md) and its associated projects.

- [ ] TCP Control Layer - RPC and Commands to manage ssessions and connections.
- [ ] User Sessions - State management of users on server and client
- [ ] UDP Data Layer - Transport audio and real time associated data like player positions on the wire.
- [ ] Channels - Allow server members to join and leave voice channels.
- [ ] Administration - Server authorative admin controls through client to allow configuration and management.
- [ ] Data Persistence - Serverside flat file database (plain text readable)
- [ ] Layer Encryption - E2E encryption for data being transmitted between server and clients (Optional with variation for level of security vs overhead)
- [ ] LUA Scripting Engine - Allow users to create scripts server and client side that can interpret data and modify packet metadata for users.
